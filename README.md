# Lộ trình học Tkinter - UHL

Dự án thực hành theo 4 lộ trình học Tkinter của môn Lập trình Python - Trường Đại học Hạ Long.

## Cấu trúc dự án

| File | Lộ trình | Mô tả |
|------|----------|-------|
| `main.py` | Lộ trình 1 | Thiết lập dự án, cửa sổ "Lời chào UHL" |
| `the_sinh_vien.py` | Lộ trình 2 | Widget - Thẻ Sinh Viên Số với màu sắc và nút bấm |
| `form_diem_danh.py` | Lộ trình 3 | Sắp xếp giao diện Grid - Form nhập thông tin |
| `xac_nhan_diem_danh.py` | Lộ trình 4 | Xử lý sự kiện & Thu thập dữ liệu |
| `requirements.txt` | - | Danh sách thư viện cần thiết |

## Cài đặt và chạy

### 1. Tạo môi trường ảo
```bash
python -m venv .venv
```

### 2. Kích hoạt môi trường ảo
```bash
# Windows
.venv\Scripts\activate

# Mac/Linux
source .venv/bin/activate
```

### 3. Cài đặt thư viện
```bash
pip install -r requirements.txt
```

### 4. Chạy từng bài
```bash
python main.py                  # Lộ trình 1
python the_sinh_vien.py         # Lộ trình 2
python form_diem_danh.py        # Lộ trình 3
python xac_nhan_diem_danh.py    # Lộ trình 4
```
